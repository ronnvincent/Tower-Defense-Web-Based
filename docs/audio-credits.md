## Verification

Each of the 60 files was checked after conversion, not before:

1. **Downloaded** — fetched from the URL in the table above at build-44 time.
2. **Converted** — one pass of libvorbis (-q:a 2, 3 ms fade in/out,
   per-family RMS normalisation, -0.95 dBFS peak ceiling).
3. **Header checked** — the first four bytes are `OggS` (real Ogg container,
   not a renamed MP3 or a zero-length placeholder).
4. **Decoded end-to-end** — every file was decoded by ffmpeg and the resulting
   PCM length was compared with the intended duration; a truncated or corrupt
   file fails this step.
5. **In the test suite** — `tests/audio-library.test.js` re-checks that every
   path named in the catalogue exists on disk, is at least 1 KiB, and starts
   with the `OggS` magic, on every run.

## Limitations, recorded honestly

- **No defeat music.** The music pack has no track that reads as a loss, and no
  other CC0 source was reachable from the sandbox. Defeat therefore stops the
  recorded bed and plays the `cue.defeat` sting over the existing procedural
  bed. This is documented, not faked with an unrelated track.
- **No dedicated wing sound.** Airborne creeps reuse the footstep recording
  pitched up ×1.9 and attenuated; there is no flyer-specific sample in any pack
  that was reachable.
- **Two Kenney UI packs overlap.** `kenney-ui` and `kenney-interface` both
  contain switch/rollover recordings; the two used here (`switch5`,
  `rollover1`) are drawn from the UI pack, the rest from Interface Sounds.
- **Original pack files are `.wav`/`.ogg`/`.mp3`** — the names in the table
  are the upstream names; the shipped files are renamed to the game's
  vocabulary (`wall.woodHit`, `tower.mortar`) so the catalogue reads like the
  game and not like a file dump.
